Behind the green check

Review a concrete fault,
not a quality score.

Removing a check can be intentional. TestDelta supplies a specific example for your review, with the execution history behind it.

01 /

Start with a test-only change.

Compare committed pytest revisions with source, helpers, configuration, and dependencies unchanged.

02 /

Apply the same selected fault.

Generate a bounded set of mutations with Cosmic Ray, then materialize identical mutation bytes for both suites.

03 /

Check the evidence.

A lost detection needs three consistent old/new pairs and valid final controls. Errors and unfinished work stay inconclusive.

Try a small, trusted project

Bring it to your
next test-only PR.

Prepare your project’s test environment, define the selected paths, and use a pinned Action.

.testdelta.toml

source_modules = ["src/pricing.py"]
test_paths = ["tests/test_pricing.py"]

Replace the example paths and dependency command. Commit the manifest before the compared test change, or use the documented external config.

GitHub Action guide ↗
.github/workflows/testdelta.yml
name: TestDelta evidence
on: pull_request

permissions:
  contents: read

jobs:
  compare:
    runs-on: ubuntu-latest
    timeout-minutes: 10
    steps:
      - uses: actions/checkout@d23441a48e516b6c34aea4fa41551a30e30af803
        with:
          fetch-depth: 0
          persist-credentials: false
      - uses: actions/setup-python@ece7cb06caefa5fff74198d8649806c4678c61a1
        with:
          python-version: '3.13'
      # Use your project's locked test dependency setup.
      - run: python -m pip install -r requirements-test.txt
      - name: Compare test revisions
        uses: hyscodebase/testdelta@2add31061b995a50a62fbf15b1a28942214f9fce
        with:
          base: ${{ github.event.pull_request.base.sha }}
          head: ${{ github.event.pull_request.head.sha }}
          python: python
          max-mutants: '10'
          budget-seconds: '120'

Requires Python 3.11–3.13, Git, and uv. Install from the repository; a PyPI release is not assumed.

The demo executes a synthetic Git comparison using actual Cosmic Ray mutations and pytest. Open .testdelta/demo/report.html for the report.

A deliberate first scope

Know what you’re running.

Python + pytest
Python 3.11–3.13. The native Action supports Ubuntu and macOS; Windows is outside its current scope.
Local execution
No LLM or API key in the comparison core. Prepare your own project dependencies; reports stay local unless you share them.
Trusted code only
Temporary workspaces are not a sandbox. Tests retain the runner user’s filesystem and network access.
